Saved sites

Domains with an automatic shade level. Adjust a slider to change the level for that domain, or set it to 0 (or use Remove) to stop shading it automatically. Edit a domain name to rename it — use * as a wildcard, e.g. *adminer* matches any site whose address contains "adminer", and *.google.com matches google.com and its subdomains.
